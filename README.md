# Саймон — Arduino Uno

Временное решение: общая шина UART/I²C. Uno «Провода» служит шлюзом от ESP32 к Саймону и лабиринту. Общая схема и протокол описаны в [docs/bus.md](docs/bus.md).

## Подключение

| Элемент | Подключение |
|---|---|
| TM1637 CLK / DIO | D2 / D4 |
| RGB-светодиод игры R / G / B | D3 / D5 / D6, каждый через резистор 220–330 Ом |
| Общий вывод RGB | 5V для общего анода, GND для общего катода |
| Лента сложности, 2 WS2812 | DIN → D7 |
| Лента прогресса, 4 WS2812 | DIN → D8 |
| Кнопки 1 / 2 / 3 | A1 / A2 / A3, вторым контактом → GND |
| Кнопка 4 | **D9**, вторым контактом → GND (перенесена с A4) |
| Кнопка 5 | **D10**, вторым контактом → GND (перенесена с A5) |
| I²C SDA | A4 → A4 wires и A4 labyrinth |
| I²C SCL | A5 → A5 wires и A5 labyrinth |
| Земля | Общий GND всех плат |

Питание модулей индикации — 5V и GND. В цепи DIN каждой ленты — резистор около 330 Ом. Общие SDA/SCL подтягиваются двумя резисторами 4,7 кОм к 5V на шлюзе. К ESP32 эти линии напрямую не подключаются. Адрес Саймона — **0x11**, лабиринта — 0x12; только wires начинает обмен на I²C.

## Настройки и запуск

В `src/main.cpp`: `COMMON_ANODE = true` для RGB с общим анодом, `SIMON_BRIGHTNESS = 30` — яркость игрового RGB 0–255. Яркость лент установлена в `setup()` на 60. TM1637 — яркость 5. После изменений прошивку загрузить заново.

После включения индикация выключена, модуль ждёт команду. В веб-пульте отправить сид и сложность через существующую подготовку задания «Провода», затем нажать D21 на ESP32. Шлюз передаёт одинаковые параметры всем головоломкам. Саймон показывает четырёхзначный сид и начинает первый этап. Перезагрузка возвращает ожидание команды.

Задание формируется по `randomSeed(seed + 1)`. Одинаковые сид и сложность дают одинаковые последовательности; повтор того же ID раунда не сбрасывает прогресс. Новое нажатие D21 создаёт новый ID и начинает игру заново с подготовленными параметрами.

## Решение и индикация

| Сложность | Длины последовательностей по этапам | Цвета |
|---|---|---|
| Лёгкая | 3, 3, 4 | Красный, жёлтый, зелёный, синий, белый |
| Средняя | 3, 4, 5 | Все девять цветов палитры |
| Сложная | 4, 5, 6 | Все девять цветов палитры |

Лента D7, первый светодиод: зелёный — лёгкая, жёлтый — средняя, красный — сложная. Первые три светодиода ленты D8 показывают этапы: пройденные зелёные, текущий мигает жёлтым, остальные выключены. При неверном нажатии текущий индикатор на 500 мс становится красным.

Игровой RGB показывает последовательность: 500 мс цвет, 250 мс пауза, затем 2 секунды между повторами. По таблице руководства переведите каждый цвет в кнопку и введите последовательность. Ввод разрешён во время показа.

Неверная кнопка обнуляет ввод текущего этапа, пройденные этапы сохраняются. Малая ошибка учитывается в счётчике I²C; мастер назначает штраф однократно. Кнопки имеют антидребезг 30 мс, удержание не создаёт повторных нажатий.

Между этапами пауза 800 мс без блокировки I²C. После третьего этапа все три индикатора зелёные, игровой RGB выключен, модуль сообщает SOLVED и ждёт новый раунд. Готовые параметры пакета из ISR применяются в `loop()`, не в прерывании.

## Сборка и проверка

Из папки этого проекта:

```powershell
pio run
pio run -t upload
pio device monitor
python test/check_bus.py
```

Монитор — 115200 бод. COM-порт для этой Uno пока не закреплён: перед загрузкой при нескольких платах укажите правильный `upload_port` в `platformio.ini` или через `--upload-port`. Не используйте автоматически порт другой головоломки.
