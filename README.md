# Саймон на ATmega328P

Проект PlatformIO для Uno, 16 МГц. Прошивка использует avr-libc и регистры AVR.
Arduino framework, Wire, TM1637Display и Adafruit NeoPixel больше не нужны.

ESP32 по-прежнему передаёт команды через шлюз wires. Simon — ведомый I²C с
адресом **0x11**, пакетами по 20 байт и CRC-16. Формат совместим с текущим wires
и labyrinth. Отдельная библиотека puzzle_bus пока не подключается.

## Структура

- `src/main.cpp` — запуск оборудования и основной цикл.
- `Application` — связывает игру, кнопки, обмен и индикацию.
- `game/Puzzle` — генератор последовательностей, совместимый с прежним AVR random.
- `game/Rules` — таблицы ответов и выбор столбца по сиду.
- `game/Game` — этапы, ввод, ошибки и автомат показа цветов.
- `game/Buttons` — антидребезг пяти кнопок.
- `game/Display` — формирование цветов лент, RGB и цифр.
- `communication/Node` — команды шлюза и состояние головоломки.
- `drivers` — GPIO/PWM, Timer1, TWI slave, TM1637 и WS2812.

Параметры игры, интервалы, яркость, общий анод/катод и вывод решения в USB UART
находятся в [include/Config.h](include/Config.h). Таблицы правил находятся отдельно
в `src/game/Rules.cpp`. Распиновка фиксирована драйверами под эту плату.

## Подключение

| Элемент | Пины Uno |
|---|---|
| TM1637 CLK / DIO | D2 / D4 |
| RGB R / G / B | D3 / D5 / D6, через резисторы 220–330 Ом |
| Общий вывод RGB | 5V для общего анода, GND для общего катода |
| Лента сложности, 2 WS2812 | D7 |
| Лента прогресса, 4 WS2812 | D8 |
| Кнопки 1 / 2 / 3 / 4 / 5 | A1 / A2 / A3 / D9 / D10, второй контакт GND |
| I²C SDA / SCL | A4 / A5 |
| USB UART TX | D1, 115200 бод |

Питание индикации — 5V, земля общая. На DIN каждой ленты — резистор около 330 Ом.
Для I²C остаётся один комплект внешних подтяжек 4,7 кОм к 5V на шлюзе.
ESP32 напрямую к этой шине 5V не подключается. TM1637 использует открытый сток,
линии CLK/DIO должны иметь подтяжки, обычно уже установленные на модуле.

## Поведение игры

После включения Simon ждёт задание с выключенной индикацией. Новый ID раунда
запускает игру. Повтор того же ID подтверждается текущим состоянием и сохраняет
прогресс, даже если в повторе изменены сид или сложность.

Четыре цифры сида выводятся с ведущими нулями. Генератор и правила сохраняют
прежние задания для сидов 0000–9999. Генератор продолжается между этапами.

| Сложность | Длины этапов | Цвета |
|---|---|---|
| Лёгкая | 3, 3, 4 | Красный, жёлтый, зелёный, синий, белый |
| Средняя | 3, 4, 5 | Все девять цветов |
| Сложная | 4, 5, 6 | Все девять цветов |

RGB показывает цвет 500 мс, выключается на 250 мс, между повторами пауза 2 с.
Ввод разрешён во время показа. Ошибка сбрасывает только ввод текущего этапа,
увеличивает накопительный счётчик и зажигает красный индикатор на 500 мс.
После этапа пауза 800 мс, после третьего этапа состояние SOLVED сохраняется.

Кнопки имеют антидребезг 30 мс. Удержание не повторяет ввод, кнопка, зажатая
при старте раунда, должна быть отпущена перед следующим нажатием.
Одновременные нажатия обрабатываются по номеру кнопки, как раньше.
Нажатия в паузе между этапами поглощаются.

Пройденные этапы светятся зелёным, текущий мигает жёлтым каждые 400 мс.
На ленте сложности первый пиксель зелёный/жёлтый/красный, остальные неиспользуемые
пиксели выключены. STOP текущего раунда выключает индикацию, RESET также
сбрасывает ID раунда и счётчик ошибок. Возобновление после STOP требует нового ID
либо RESET. При перезагрузке прогресс теряется и шлюз повторяет текущее задание.

## Драйверы и ограничения

Timer0 управляет PWM на D5/D6, Timer2 — PWM на D3. Timer1 формирует миллисекунды,
обслуживается прерыванием TIMER1_COMPA. Аппаратный TWI использует TWI_vect.
Эти ресурсы нельзя одновременно занимать другими драйверами.

В TWI ISR только принимаются байты и выдаётся готовый снимок состояния.
CRC, команды, игра и индикация обрабатываются в основном цикле.
Неполные и слишком длинные записи отбрасываются. Почтовый ящик хранит одну
непрочитанную команду, следующая запись её не затирает. Шлюз повторяет GENERATE,
пока не увидит нужный ID в состоянии.

Ответ фиксируется в начале каждого чтения и не меняется посередине кадра.
Лишние прочитанные байты заполняются нулями. Счётчик ошибок насыщается на 65535.

TM1637 проверяет ACK и повторяет неудачное обновление через 100 мс, не зависая
при отключённом дисплее. Обмен выполняется с включёнными прерываниями.
WS2812 требует запрета прерываний на 60/120 мкс для лент 2/4 пикселя.
Аппаратный TWI в это время растягивает SCL до обслуживания ISR.
Пауза сброса WS2812 выдерживается без блокирующего ожидания.

Вывод ожидаемых кнопок в USB UART включается через DEBUG_SOLUTION.
По умолчанию он выключен. Электрические уровни, цвета RGB и реальные временные
диаграммы WS2812/TWI/TM1637 необходимо проверить на плате. Компьютерные тесты
проверяют модели регистров и логику, физический стенд ими не заменяется.

## Сборка и тесты

Из папки simon:

```powershell
pio run
python test/run_tests.py
```

Для тестов нужен g++ в PATH. Также работает прежняя команда
`python test/check_bus.py`. Тесты собирают реальные игровые и коммуникационные
файлы, а драйверы — с моделями регистров AVR.

Проверяются все 30 000 сочетаний сида/сложности и все три этапа по эталонным хешам
исходной прошивки, ошибки/победа/остановка, точные границы интервалов, переполнение
uint32, дребезг, удержание, повреждение каждого бита пакета, дубликаты команд,
переполнение счётчика, длины TWI 0–80, целостность снимка ответа и байты TM1637.

Загрузка выполняется отдельно командой `pio run -t upload --upload-port COMx`.
Порт этой Uno не закреплён. Сборка и тесты ничего на платы не загружают.
